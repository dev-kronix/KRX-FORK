# Changelog

Todas as mudanças relevantes da KRX API serão registradas neste arquivo.

## 0.1.0 - 2026-10-03

### Projeto

- Fork adotado oficialmente como base da KRX API.
- Identidade do pacote alterada para `krx-api`.
- Documentação principal reescrita em português do Brasil.
- Domínio oficial definido como `krxdev.tech` para site e API.
- Swagger identificado como KRX API e configurado com servidores de produção e desenvolvimento.

### Internacionalização

- `pt-BR` definido como idioma padrão.
- `Accept-Language` definido como header padrão de idioma.
- Traduções iniciais adicionadas para confirmação de e-mail, alteração de e-mail e recuperação de senha.

### Configuração

- Exemplo de ambiente de produção adicionado.
- Identidade de e-mail padrão alterada para KRX.
- Requisitos de runtime alinhados para Node.js 24+ e npm 11+.

## Origem

A KRX API foi inicialmente derivada do projeto open source `brocoders/nestjs-boilerplate`, licenciado sob MIT. O histórico anterior permanece disponível no histórico Git do fork.
